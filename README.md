# 🚀 AgentPulse: Agentic Sports Intelligence

**AgentPulse** is a next-generation tactical sports dashboard powered by **Google Gemini 1.5 Pro**. It serves as the "Command Center" of the Agentic Sports Ecosystem, providing real-time match telemetry, predictive analytics, and automated coaching insights for high-level football strategy.

## 🔗 Live Deployment
[**View Live Dashboard**](https://g-apl-service-94343063153.asia-south1.run.app/)

---

## 💎 Key Features
*   **Agentic Reasoning Engine**: Leverages AI to process live match data and generate tactical insights (e.g., *Formation adjustments, defensive vulnerabilities*).
*   **Real-Time Telemetry**: Tracks critical metrics like possession flux, pressing intensity, and expected goals (xG).
*   **Holographic UI**: Built with a custom "Neon-Glassmorphism" design system, featuring dynamic glowing elements, scanlines, and high-frequency UI updates.
*   **Global Accessibility**: Integrated with Google Translate for instant localized access across 100+ languages.

## 🛠️ Technology Stack
*   **Frontend**: HTML5, Vanilla JavaScript, CSS3 (Custom Glassmorphism Framework)
*   **AI Integration**: Simulated Gemini 1.5 Pro Agentic Logic
*   **Deployment**: Docker, Nginx, Google Cloud Run
*   **Global Services**: Google Translate API

## 🚀 Quick Start (Local Development)

1. Clone the repository:
   ```bash
   git clone https://github.com/vishnu-priya99/agentic-sports-ecosystem.git
   cd agentic-sports-ecosystem
   ```
2. Run with Docker:
   ```bash
   docker build -t agentpulse .
   docker run -p 8080:80 agentpulse
   ```
3. Open `http://localhost:8080` in your browser.
